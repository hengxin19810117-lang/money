## 三、高风险功能

### 🔴 高风险

| 功能 | 风险描述 | 风险原因 |
|------|---------|---------|
| **认证模块** | Token伪造、密码泄露 | JWT密钥硬编码、密码强度验证缺失 |
| **财务计算** | 金额错误、数据丢失 | Decimal精度问题、预算超支逻辑缺陷 |
| **数据导出** | 文件注入、大数据量OOM | xlsx库安全性、内存溢出风险 |
| **管理后台** | 越权操作、敏感数据泄露 | 权限控制不完善、用户名明文传输 |

### 🟡 中风险

| 功能 | 风险描述 | 风险原因 |
|------|---------|---------|
| **记录CRUD** | 数据无法恢复 | 删除无软删除、级联删除问题 |
| **分类管理** | 分类下有记录时删除 | 外键约束缺失或处理不当 |
| **API接口** | SQL注入、参数校验 | 缺乏输入验证 |

-- 存储过程: 生成指定数量的测试记录
DELIMITER //
CREATE PROCEDURE generate_test_records(IN user_id VARCHAR(50), IN record_count INT)
BEGIN
  DECLARE i INT DEFAULT 0;
  DECLARE random_amount DECIMAL(12,2);
  DECLARE random_date DATE;
  
  WHILE i < record_count DO
    SET random_amount = FLOOR(RAND() * 10000) / 100;
    SET random_date = DATE_SUB(CURDATE(), INTERVAL FLOOR(RAND() * 365) DAY);
    
    INSERT INTO records (id, user_id, type, amount, category_id, note, record_date, created_at)
    VALUES (
      CONCAT('rec_test_', user_id, '_', i),
      user_id,
      IF(RAND() > 0.3, 'expense', 'income'),
      random_amount,
      (SELECT id FROM categories WHERE is_system = 1 ORDER BY RAND() LIMIT 1),
      CONCAT('测试记录_', i),
      random_date,
      NOW()
    );
    
    SET i = i + 1;
  END WHILE;
END //
DELIMITER ;

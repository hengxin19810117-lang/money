## 一、项目概述

### 1.1 产品简介

**财务小管家**是一款面向个人的轻量级记账应用，帮助用户简单、快速地记录每日消费情况，随时了解资金流向。

**核心价值**：
- **快**：3秒记一笔
- **清**：随时知道钱花哪儿了
- **省**：直观看到支出结构，减少不必要的花费

## 五、用户角色分析

### 5.1 角色定义

| 角色 | 说明 | 权限范围 |
|------|------|---------|
| **普通用户** | 使用记账功能的个人用户 | 仅可操作自己的数据 |
| **管理员** | 系统运营管理人员 | 可查看所有用户数据、统计报表 |

### 5.2 普通用户功能

| 功能模块 | 操作 | 说明 |
|---------|------|------|
| 认证 | 注册、登录、登出 | 用户名密码认证 |
| 记账 | 创建、编辑、删除记录 | 支出/收入分类记录 |
| 分类 | 查看系统分类 | 使用预置分类 |
| 预算 | 设置、查看预算 | 按月/周/年周期 |
| 统计 | 查看月度/年度统计 | 图表展示 |
| 导出 | 导出数据 | Excel/CSV格式 |

### 5.3 管理员功能

| 功能模块 | 操作 | 说明 |
|---------|------|------|
| 登录 | 管理后台登录 | 独立账号体系 |
| 仪表盘 | 查看系统概览 | 用户数、记录数、趋势 |
| 用户管理 | 查看、禁用用户 | 不可修改用户数据 |
| 记录管理 | 查看所有记录 | 不可修改或删除 |
| 统计报表 | 查看全局统计 | 支出/收入排行、分类占比 |

## 六、核心业务流程

### 6.1 用户注册登录流程

```
用户                          后端                          数据库
 │                             │                              │
 │  POST /api/auth/register    │                              │
 │────────────────────────────>│                              │
 │                             │  验证用户名唯一性              │
 │                             │─────────────────────────────>│
 │                             │                              │
 │                             │  bcrypt.hash(password)       │
 │                             │─────────────────────────────>│
 │                             │                              │
 │                             │  INSERT INTO users           │
 │                             │─────────────────────────────>│
 │                             │                              │
 │  { success: true, token }   │                              │
 │<────────────────────────────│                              │
 │                             │                              │
 │  POST /api/auth/login       │                              │
 │────────────────────────────>│                              │
 │                             │  查找用户                    │
 │                             │─────────────────────────────>│
 │                             │                              │
 │                             │  bcrypt.compare(password)    │
 │                             │─────────────────────────────>│
 │                             │                              │
 │                             │  jwt.sign({ userId })        │
 │                             │                              │
 │  { success: true, token }   │                              │
 │<────────────────────────────│                              │
```

### 6.2 记账记录流程

```
用户                          后端                          数据库
 │                             │                              │
 │  POST /api/records          │                              │
 │  { type, amount, categoryId }                              │
 │  + Authorization: Bearer    │                              │
 │────────────────────────────>│                              │
 │                             │  验证Token                   │
 │                             │─────────────────────────────>│
 │                             │                              │
 │                             │  验证必填字段                │
 │                             │  amount > 0                  │
 │                             │                              │
 │                             │  INSERT INTO records         │
 │                             │─────────────────────────────>│
 │                             │                              │
 │  { success: true }          │                              │
 │<────────────────────────────│                              │
```

### 6.3 数据导出流程

```
用户                          后端                          数据库
 │                             │                              │
 │  GET /api/records/export    │                              │
 │  ?startDate&endDate&format  │                              │
 │────────────────────────────>│                              │
 │                             │  查询指定日期范围记录         │
 │                             │─────────────────────────────>│
 │                             │                              │
 │                             │  生成Excel/CSV文件           │
 │                             │                              │
 │  { success: true, data }    │                              │
 │  (文件数据/下载链接)         │                              │
 │<────────────────────────────│                              │
```

### 6.4 管理后台访问流程

普通用户                      管理后台                      主后端

   │                             │  POST /api/admin/login       │

## 七、数据模型

### 7.1 数据库表结构

#### users (用户表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | VARCHAR(50) | 主键 |
| username | VARCHAR(50) | 用户名，唯一 |
| password | VARCHAR(100) | 密码哈希 |
| nickname | VARCHAR(50) | 昵称 |
| avatar | TEXT | 头像URL |
| email | VARCHAR(100) | 邮箱 |
| phone | VARCHAR(20) | 手机号 |
| status | TINYINT | 状态: 0-禁用, 1-正常 |
| created_at | DATETIME | 创建时间 |
| last_login_at | DATETIME | 最后登录时间 |

#### categories (分类表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | VARCHAR(50) | 主键 |
| name | VARCHAR(50) | 分类名称 |
| type | ENUM | 'expense'/'income' |
| icon | VARCHAR(50) | 图标名称 |
| color | VARCHAR(20) | 颜色值 |
| sort_order | INT | 排序 |
| is_system | TINYINT | 是否系统分类 |
| user_id | VARCHAR(50) | 所属用户(NULL表示系统) |

#### records (记账记录表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | VARCHAR(50) | 主键 |
| user_id | VARCHAR(50) | 用户ID (外键) |
| type | ENUM | 'expense'/'income' |
| amount | DECIMAL(12,2) | 金额 |
| category_id | VARCHAR(50) | 分类ID (外键) |
| note | VARCHAR(500) | 备注 |
| merchant | VARCHAR(100) | 商户 |
| payment_channel | VARCHAR(50) | 支付渠道 |
| record_date | DATE | 记账日期 |
| created_at | DATETIME | 创建时间 |

#### budgets (预算表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | VARCHAR(50) | 主键 |
| user_id | VARCHAR(50) | 用户ID (外键) |
| category_id | VARCHAR(50) | 分类ID (外键，NULL表示总预算) |
| amount | DECIMAL(12,2) | 预算金额 |
| period_type | ENUM | 'daily'/'weekly'/'monthly'/'yearly' |
| start_date | DATE | 开始日期 |
| end_date | DATE | 结束日期 |

#### payment_channels (支付渠道表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | VARCHAR(50) | 主键 |
| name | VARCHAR(50) | 渠道名称 |
| icon | VARCHAR(50) | 图标 |
| color | VARCHAR(20) | 颜色 |
| user_id | VARCHAR(50) | 所属用户(NULL表示通用) |

#### login_logs (登录日志表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | VARCHAR(50) | 主键 |
| user_id | VARCHAR(50) | 用户ID |
| ip_address | VARCHAR(50) | IP地址 |
| login_status | TINYINT | 0-失败, 1-成功 |
| fail_reason | VARCHAR(200) | 失败原因 |
| login_at | DATETIME | 登录时间 |

## 十二、常见问题

### Q1: 如何启动项目？

**主应用：**
```bash
# 终端1: 启动后端
cd backend
node index.js

# 终端2: 启动前端
cd fronted-react
npm run dev
```

**管理后台：**
```bash
# 终端1: 启动管理后端
cd admin-panel/backend
node index.js

# 终端2: 启动管理前端
cd admin-panel/frontend
npm run dev
```

### Q2: 默认账号是什么？

- 普通用户: `testuser` / `123456`
- 管理员: `admin` / `admin123`

### Q3: 数据库连接失败？

检查 `backend/config/db.js` 中的数据库配置：
- 主机: localhost
- 端口: 3306
- 用户: root
- 密码: 123456
- 数据库: money

### Q4: 端口被占用？

```bash
# 查看端口占用
netstat -ano | grep 3000

# 结束进程
taskkill /PID <进程ID> /F
```

## 1. 产品概述

### 1.1 产品简介
**财务小管家**是一款面向个人的轻量级记账应用，帮助用户简单、快速地记录每日消费情况，随时了解资金流向。

### 1.2 目标用户
- 需要日常记录消费的个人用户
- 希望了解支出构成的小白用户
- 追求简单操作、不想花太多时间记账的用户

### 1.3 核心价值
- **快**：3秒记一笔
- **清**：随时知道钱花哪儿了
- **省**：直观看到支出结构，减少不必要的花费

## 2. 功能需求

### 2.1 用户系统

#### 2.1.1 注册
用户可以通过用户名和密码注册账号。

| 字段 | 类型 | 说明 |
|------|------|------|
| 用户名 | 必填 | 3-20位字母或数字，唯一 |
| 密码 | 必填 | 6-20位 |
| 确认密码 | 必填 | 与密码一致 |

#### 2.1.2 登录
用户可以使用用户名和密码登录。

| 字段 | 类型 | 说明 |
|------|------|------|
| 用户名 | 必填 | - |
| 密码 | 必填 | - |
| 记住登录 | 选填 | 7天内免登录 |

#### 2.1.3 登出
用户可以随时退出登录状态。

### 2.2 核心功能

#### 2.2.1 记一笔
用户可以快速记录一笔支出或收入。

| 字段 | 类型 | 说明 |
|------|------|------|
| 金额 | 必填 | 数字输入，支持小数 |
| 类型 | 必填 | 支出 / 收入 |
| 分类 | 必填 | 餐饮、交通、购物、居住、娱乐、医疗、教育、其他 |
| 日期 | 必填 | 默认当天，支持选择历史日期 |
| 备注 | 选填 | 简短说明（最多50字） |

#### 2.2.2 账单列表
- 按日期倒序展示所有记账记录
- 支持按月份筛选
- 每条记录显示：金额、分类图标、备注、日期
- 点击可编辑或删除

#### 2.2.3 统计报表
- **本月支出**：显示当月总支出金额
- **分类占比**：饼图展示各分类支出占比
- **TOP 3 分类**：列出支出最多的三类

#### 2.2.4 数据管理
- 导出数据为 Excel/CSV（按月份）
- 数据跟随用户账户，云端存储（后续版本）

### 2.3 非功能需求

| 需求 | 说明 |
|------|------|
| 性能 | 页面加载 < 1秒，操作响应 < 200ms |
| 容量 | 支持至少 3 年数据（~10000 条） |
| 适配 | 支持手机端（优先），平板端 |
| 离线 | 无网络时正常使用（本地缓存） |
| 安全 | 密码加密存储，Session 令牌认证 |

## 7. 风险与假设

| 风险/假设 | 影响 | 应对 |
|----------|------|------|
| 用户不愿每天打开App | 中 | 优化快捷入口，3秒完成记录 |
| 数据安全 | 高 | 密码加密存储，Token认证 |
| 账户被盗 | 中 | 密码强度校验，安全提示 |
| 手机适配 | 中 | 移动端优先开发 |

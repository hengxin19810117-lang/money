# 财务小管家 - 后台管理系统 PRD

## 1. 项目概述

### 1.1 产品背景
财务小管家是一款面向个人/家庭的轻量级记账应用，用户通过移动端或 Web 端记录日常收支，系统提供统计报表帮助用户了解财务状况。

### 1.2 后台管理系统目的
为应用运营方提供用户管理、数据查看、业务统计等功能，便于：
- 了解用户增长及活跃情况
- 查看用户记账数据（脱敏）
- 监控系统运行状态
- 业务数据统计分析

### 1.3 设计约束
- **禁止修改数据库及数据库表结构**
- 后台管理系统独立部署，不影响主应用
- 数据权限：管理员仅可查看，脱敏处理

## 5. 技术方案（待定）

### 5.1 技术栈建议
| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端 | React + Vite | 与现有前端保持一致 |
| UI组件 | Tailwind CSS | 与现有前端保持一致 |
| 图表 | Recharts | 与现有前端保持一致 |
| 后端 | Node.js / Java | 与现有后端技术对齐 |
| 数据 | 读写现有数据库（只读） | 禁止修改表结构 |

### 5.2 接口设计原则
- 管理员接口统一添加 `/admin` 前缀
- 所有接口需要管理员 Token 鉴权
- 数据查询均为只读操作
- 返回数据按需脱敏

### 5.3 安全性
- 管理员账号独立于用户账号
- 密码使用 bcrypt 加密
- 接口请求频率限制
- 操作日志记录（可选）

---

## 6. 备注

1. **数据权限**：后台系统仅提供数据查看功能，不提供数据修改/删除
2. **性能考虑**：大表查询需添加索引（由 DBA 评估），后台系统不直接建索引
3. **数据脱敏**：用户名只展示脱敏版本（如 `zh***`），完整用户名仅管理员可见
4. **后续扩展**：如需导出功能，可基于现有 export 接口扩展 Excel 导出

## 7. 附录：现有数据库表结构（参考）

> 以下为现有表结构，后台系统只读访问，**禁止修改**

### users 表
```sql
- id (varchar, PK)
- username (varchar)
- password (varchar, encrypted)
- nickname (varchar, nullable)
- avatar (text, nullable)
- created_at (datetime)
- last_login_at (datetime)
```

### records 表
```sql
- id (varchar, PK)
- user_id (varchar, FK)
- type (varchar) -- 'expense' or 'income'
- amount (decimal)
- category_id (varchar)
- note (varchar, nullable)
- merchant (varchar, nullable)
- payment_channel (varchar, nullable)
- record_date (date)
- created_at (datetime)
```

### categories 表
```sql
- id (varchar, PK)
- user_id (varchar, nullable) -- null 表示系统分类
- name (varchar)
- icon (varchar)
- color (varchar)
- type (varchar) -- 'expense' or 'income'
```
